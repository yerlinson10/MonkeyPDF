# Design — MonkeyPDF

Locked system. App screens share this fingerprint.

## Genre
playful-técnico · press-shop / banana stamp

## Identity (non-negotiables)
- **One typeface only:** Syne (weights 500–800 create hierarchy)
- **No second “mono” family** — paths use Syne + tabular nums
- **Desk + sheet:** dark green-ink rail, white PDF sheet with hard offset shadow
- **Banana** is the only loud color — stamp blocks, active tool, primary CTA
- **Hard borders + stamp shadows** (4px 4px 0), never soft SaaS blur
- **No gradients** as decoration (desk grid dots only)
- **No emoji** — SVG outline icons
- **Scrollbars** — thin stamp strips (ink border + 1px offset); banana thumb on hover; desk rail uses dark track
